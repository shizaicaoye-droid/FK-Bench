# FKBench v0.2

フォルダ構成を保って静的ホスティングに配置するか、ローカルHTTPサーバーで開いてください。Pythonの場合は `python -m http.server 8000` を実行し、http://localhost:8000 を開きます。

## 追加内容
- スマホ対応のホーム画面
- プロトコルの作成・編集・削除、チェックリスト、実施メモ
- 複数タイマー（開始・一時停止・再開・再スタート、再読み込み後の復元）
- JSONバックアップと追加読込
- 既存の3種類の希釈計算を保持、非有限値と過剰な段階数の入力を拒否

## 制限
記録は同じオリジンのブラウザ内に保存されます。自動同期・サーバー送信はありません。定期的にバックアップを書き出してください。ブラウザのデータ削除で記録が失われます。手順を変更して保存するとチェックをリセットします。読込時は現在のデータに追加し、読み込んだタイマーは停止します。

タイマー音は画面ロックやバックグラウンドで保証されません。重要な待ち時間には端末の標準タイマーも使用してください。PWAインストール、オフライン起動、OS通知、ストア配布はまだ未実装です。
