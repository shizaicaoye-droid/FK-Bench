### Issue #3

ピペット量警告システム

判定基準

🟢 20 µL以上
問題なし

🟡 2〜20 µL
少量操作です。ピペッティング誤差に注意してください。

🔴 2 µL未満
P20の推奨範囲外です。段階希釈を検討してください。
